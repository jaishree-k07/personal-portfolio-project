# Personal Portfolio Landing Page

A beginner-friendly responsive portfolio made with semantic HTML5 and CSS3, following the uploaded Project 01 learner guide.

## Files
- `index.html` — page structure and content
- `style.css` — purple/lilac theme, Flexbox/Grid layouts, responsive media queries, hover and keyboard-focus styles
- `images/` — folder reserved for your own images (optional)

## Run locally
1. Download and extract this project folder.
2. Open `index.html` in Chrome, Edge, or Firefox. For live refresh, open the folder in VS Code and use the Live Server extension.
3. Test at mobile (360px), tablet (768px), and desktop (1280px) widths.

## Personalise before submitting
Search `index.html` for `Your Name`, `your.email@example.com`, and the example GitHub/LinkedIn URLs. Replace these with your own details. Replace the two starter project descriptions with real projects and add their repository/demo links. Do not claim skills or projects you have not worked on.

## Publish free with GitHub Pages
1. Create a GitHub repository and upload `index.html`, `style.css`, and any images.
2. In the repository, open **Settings → Pages**.
3. Choose deployment from the `main` branch and `/ (root)`, then save.
4. Wait for the published URL and open it on your phone to verify it works.

## Design decision
The portfolio uses purple and lilac as a consistent three-tone visual direction, with a responsive CSS Grid for skill/project cards and Flexbox for navigation. The layout changes on smaller screens so content remains readable and easy to tap.
